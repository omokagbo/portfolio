# Emmanuel Omokagbo Portfolio

A personal portfolio built with Vite and vanilla JavaScript.

Live site: <https://omokagbo.github.io/portfolio/>

## Project structure

- `src/index.html` is the Vite HTML entry point.
- `src/main.js` contains the portfolio content and interactions.
- `src/style.css` contains the visual styles.
- `index.html` and `assets/` at the repository root are the generated files served by GitHub Pages.

## Develop locally

```sh
npm install
npm run dev
```

Open <http://localhost:5173/portfolio/> to preview the site.

## Build and publish

```sh
npm run build
npm run preview
```

The build writes the Pages-ready `index.html` and compiled assets into the repository root. Commit those generated files along with source changes, then push to `main` to publish through the repository's GitHub Pages configuration.
